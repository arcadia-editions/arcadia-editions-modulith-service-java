# P-02 startOrderCheckout has no 409 response in the contract

status: decided A without contract change (person, 2026-11-13)
found by: T-15, implementer (claude sonnet), 2026-11-13
flow: place-order-flow
blocks: T-15

## Problem
The overlay decision "Stock unavailable" and the T-15 task say the request is answered 409 with the unavailable
items. The contract declares only `201` and `400` for `POST /orders/start-checkout`
([orders-checkout-openapi.yml:44](../../../arcadia-editions-modulith-api/orders-checkout-openapi.yml#L44)): no
`409` response and no schema for the unavailable items body. The ZDL
([orders-checkout-domain-model.zdl:95](../../../arcadia-editions-modulith-api/orders-checkout-domain-model.zdl#L95))
declares `startOrderCheckout(...) Order withEvents [OrderCreated | StockUnavailable]` and the ZFL
([place-order-flow.zfl:82](../../../arcadia-editions-architecture/business-flows/place-order-flow.zfl#L82)) emits
`StockUnavailable`, but neither defines an HTTP body. Inventing a 409 body in code would diverge from the contract.

## Evidence
`grep -n 409 orders-checkout-openapi.yml` finds nothing. Responses of start-checkout: 201 Order, 400.

## Options
- A: add `409` to the contract with a schema (problem detail with an `unavailableItems[]` extension: sku,
  requestedQuantity, availableQuantity, same as `StockUnavailableItem`). Changes: openapi, regenerated
  controller/test; no ZDL change. Impl throws a domain exception, T-04 problem-details handler maps it to 409.
- B: answer 409 as a plain problem detail without items (contract adds `409` with no schema). Loses the items
  the task asks for.

Recommendation: A, consistent with the T-04 problem-details handler and the overlay decision.

## Decision
A, decided by the person in the session, 2026-11-13: implement A now WITHOUT updating orders-checkout-openapi.yml or the ZDL (that change comes later, by the person). The implementation answers 409 with a problem detail carrying unavailableItems[] (sku, requestedQuantity, availableQuantity); it does not need the contract to declare it.
